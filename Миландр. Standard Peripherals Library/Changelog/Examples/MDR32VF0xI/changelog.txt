Список изменений примеров и примеров проектов для МК К1986ВК025 (MDR32F02), MDR1206FI, MDR1206AFI.

--------------------------------------------------------------------------------

v0.2.0 01/07/2025

Добавлено:
    ПРИМЕРЫ:
        Общие для MDR32F02, MDR1206FI, MDR1206AFI:
            1. Добавлены примеры работы ADC, ADCUI, BKP (RTC IRQ, RTC SW, Tamper), прерываний (IRQ), машинного таймера (MTIMER), FLASH, PORT, FreeRTOS (LED), TIMER (CAP, PWM), UART (Loopback).
        MDR1206FI, MDR1206AFI:
            1. Добавлены пример работы расширения XGOST.
        MDR32F02:
            1. Добавлен пример работы с OTP (перенесен из примера проекта MDR32F02_OTP_Word для Eclipse).
    ПРИМЕРЫ ПРОЕКТОВ:
        Eclipse:
            1. Добавлен шаблон проекта MDR32VF0xI_FreeRTOS_Template.
            2. В настройках добавлено расширение _zicntr (поддерживается в xPack GNU RISC-V Embedded GCC с версии v14.2.0-2 - при использовании более ранних версий xPack GNU RISC-V Embedded GCC расширение _zicntr в настройках следует убрать).
        IAR:
            1. Добавлены шаблоны проектов MDR32VF0xI_Template (общий для МК MDR32F02, MDR1206FI, MDR1206AFI), MDR32F02_Template, MDR1206_Template (общий для МК MDR1206FI, MDR1206AFI), MDR1206FI_Template, MDR1206AFI_Template.

Изменено:
    ПРИМЕРЫ ПРОЕКТОВ:
        Общее:
            1. В примерах проектов обновлена библиотека SPL MDR32VF0xI для МК MDR32F02, MDR1206FI, MDR1206AFI до версии 0.2.0.

Удалено:
    ПРИМЕРЫ ПРОЕКТОВ:
        Eclipse:
            1. Удалены примеры проектов MDR32F02_OTP_Word и MDR32VF0xI_Led (поскольку их код перенесен в примеры).
