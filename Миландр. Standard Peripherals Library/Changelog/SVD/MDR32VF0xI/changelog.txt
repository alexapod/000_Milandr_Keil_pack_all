Список изменений файлов SVD (System View Description) для МК К1986ВК025 (MDR32F02), MDR1206FI, MDR1206AFI.

--------------------------------------------------------------------------------

v.2.0 01/07/2025

Добавлено:
    MDR1206FI, MDR1206AFI:
        1. Добавлены описания битовых полей и регистров.

Изменено:
    MDR1206FI, MDR1206AFI:
        1. Изменены названия битовых полей и регистров, не совместимые с языком C (по результатам проверки утилитой SVDConv).
        2. DMA: исправлен тип доступа к регистру STATUS с read-write на read-only.
        3. I2C:
            - исправлен тип доступа к регистру RXD с read-write на read-only;
            - исправлен тип доступа к регистру STA с read-write на read-only.
        4. SSP:
            - исправлен тип доступа к регистру SR с read-write на read-only;
            - исправлен тип доступа к регистру RIS с read-write на read-only;
            - исправлен тип доступа к регистру MIS с read-write на read-only;
            - исправлен тип доступа к регистру ICR с read-write на write-only.
        5. UART: изменен тип доступа к регистру DR с write-only на read-write.
    MDR32F02:
        1. Изменены названия битовых полей и регистров, не совместимые с языком C (по результатам проверки утилитой SVDConv).
        2. CLINT: исправлено адресное пространство.
        3. L_BLOCK: исправлен номер прерывания.
        4. OTP: исправлен номер прерывания.
        5. PLIC: исправлено адресное пространство.
        6. P_BYTE:
            - исправлен тип доступа к регистру MUX_SET с read-only на read-write;
            - исправлен тип доступа к регистру MUX_VAL с read-only на read-write.

Удалено:
    MDR1206FI, MDR1206AFI:
        1. ADCUI: удален аппаратно не реализованный бит F0FAULTCONM регистра F0MASK.
        2. I2C: удален аппаратно не реализованный бит S_I2C регистра CTR.
